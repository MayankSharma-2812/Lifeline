# LifeLine — UI/UX Brief (for Stitch + build reference)

## 1. Tone
An emergency tool, not a lifestyle app — **calm urgency**. Clear, high-contrast, minimal decision fatigue. No playful illustration, no marketing-site aesthetic.

## 2. Visual Direction
- **Color:** neutral base (off-white / near-black for dark mode) with a single deep-crimson accent used only for urgent CTAs/status — never as a dominant background.
- **Typography:** highly legible sans-serif, large size for countdown timers and distances — read by someone stressed, possibly on a phone in bad lighting.
- **Density:** low — one primary action per screen.
- **Motion:** subtle animation on status-chip transitions so escalation is noticed without being jarring.
- **Accessibility:** never rely on color alone for status/timers — pair with icon + text label. Large tap targets throughout (one-handed use).

## 3. Screens Needed (MVP)
1. Signup / Login
2. Emergency Intake (free-text + optional voice icon)
3. AI-Parsed Confirmation (editable extracted fields)
4. Ranked Matches (donor cards: distance, reliability, AI one-liner, Reserve CTA)
5. Active Reservation (countdown timer, live status stepper, contact reveal on confirm)
6. Donor Dashboard (availability toggle, incoming-request card with Accept/Decline + timer)
7. Session-revoked toast (non-blocking notice)

## 4. Explicitly Out of Scope for MVP UI
Pharmacy/medicine inventory screens — documented only, not designed/built for this submission.
